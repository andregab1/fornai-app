# Permanent project instructions

- Read `IMPLEMENTATION.md` and `PLAN.md` before changing the project.
- `PLAN.md` is the source of truth for stages and progress.
- Do not invent Elementals, names, variants, identifiers, or images.
- Never erase user progress when the catalog is updated.
- Code, class names, variables, and file names must be in English.
- User-facing application text must be in Brazilian Portuguese.
- Run `dart format`, `flutter analyze`, and `flutter test` after relevant changes.
- Do not add production dependencies without documenting the justification.
- Do not reuse images without checking origin, terms, and permission.
- Do not remove watermarks or bypass authentication, blocks, or protections.
- Do not hotlink third-party images in the final application.
- Make small, reviewable changes.
- Preserve existing user changes.
- Never delete files or run destructive commands without explicit authorization.
- During planning, do not implement final features.
